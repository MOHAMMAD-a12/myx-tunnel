# 🚀 MyX Tunnel v1.3.0

**تانل ریورس پرسرعت ایران ↔ خارج** — اسکریپت حرفه‌ای مدیریت تانل با منوی رنگی کامل و نصب تک‌دستوری.

---

## ⚡ نصب تک‌دستوری

این دستور را روی سرور (ایران یا خارج) اجرا کنید:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/MOHAMMAD-a12/myx-tunnel/main/myx-tunnel.sh)
```

پس از اجرا، Wizard سه‌مرحله‌ای باز می‌شود:

1. **انتخاب حالت تانل** — Classic (IP خارج در کانفیگ) یا Reverse (IP ایران در کانفیگ)
2. **انتخاب سرور فعلی** — این سرور ایران است یا خارج
3. **انتخاب پروتکل** — FRP / Realm / Gost / IPTables / Socat / **Backhaul**

پس از نصب اولیه، دستور `myx` در هر جای سرور منوی مدیریت را باز می‌کند:

```bash
myx          # باز کردن منوی اصلی
myx menu     # باز کردن منو
myx version  # نمایش نسخه
```

## 🔌 پروتکل‌های پشتیبانی شده

| پروتکل | نوع | بهترین کاربرد |
|---|---|---|
| **FRP** | ریورس واقعی (ایران به خارج وصل می‌شود) | فیلترینگ سنگین + IP ایران مسدود |
| **Realm** | فوروارد مستقیم TCP/UDP | سبک‌ترین و کم‌مصرف‌ترین |
| **Gost** | ریورس رمزنگاری‌شده (TLS / WS / WSS) | ضد DPI و دور زدن شناسایی ترافیک |
| **IPTables** | NAT سطح کرنل | کمترین تأخیر، حداکثر سرعت |
| **Socat** | فوروارد ساده TCP/UDP | تست سریع و راه‌اندازی آسان |
| **Backhaul** | ریورس نسل جدید (TCP/WS/WSS + UDP over TCP + Multiplexing) | پرسرعت برای اتصالات همزمان زیاد |

> **Backhaul** نصب شده از ریلیز رسمی [Musixal/Backhaul](https://github.com/Musixal/Backhaul) و ترنسپورت‌های `tcp / tcpmux / ws / wss / wsmux / wssmux` را پشتیبانی می‌کند (گواهی TLS برای WSS خودکار ساخته می‌شود) + مانیتور وب.

## 🛠 راه‌اندازی سریع — حالت Classic (خروجی از ایران)

### مرحله ۱ — سرور خارج
```bash
bash myx-tunnel.sh
# Step 1/3 : [1] Classic Mode
# Step 2/3 : [2] KHAREJ server
# Step 3/3 : [1] FRP
# پورت را وارد کنید (پیش‌فرض 7000)
# ⚠️ توکن نمایش داده شده را کپی کنید!
```

### مرحله ۲ — سرور ایران
```bash
bash myx-tunnel.sh
# Step 1/3 : [1] Classic Mode
# Step 2/3 : [1] IRAN server
# Step 3/3 : [1] FRP
# IP سرور خارج + توکن + پورت سرویس روی ایران (مثلا 443) + پورت ریوت روی خارج
```

✅ کاربران از پورت سرور خارج وصل می‌شوند و ترافیک از تانل به سرویس روی سرور ایران می‌رسد.

## 🔁 حالت Reverse (IP ایران در کانفیگ، خروجی از خارج)

اگر کاربران به **IP سرور ایران** وصل شوند ولی خروجی اینترنتشان از **سرور خارج** باشد:

### با IPTables / Realm / Socat — فقط روی سرور ایران:
```bash
bash myx-tunnel.sh
# Step 1/3 : [2] Reverse Mode (IP Iran)
# Step 2/3 : [1] IRAN server
# Step 3/3 : [4] IPTables  (یا Realm / Socat)
# Listen port on THIS server         : پورت روی ایران (مثلا 8443)
# Destination server IP              : IP سرور خارج
# Target service port on destination : پورت سرویس روی خارج (مثلا 443)
```

### با FRP برعکس — روی هر دو سرور:
| سرور | مراحل Wizard |
|---|---|
| **ایران (لیستنر)** | Step1: `[2] Reverse Mode` → Step2: `[1] IRAN server` → Step3: `[1] FRP` → پورت بایند + توکن |
| **خارج (سرویس)** | Step1: `[2] Reverse Mode` → Step2: `[2] KHAREJ server` → Step3: `[1] FRP` → IP ایران + توکن + پورت سرویس روی خارج + پورت ریوت روی ایران |

⚠️ **شرط:** پورت لیستن روی سرور ایران باید برای کاربران ایرانی باز و قابل دسترسی باشد.

## 🎯 نکات حرفه‌ای برای سرعت بالا

1. **همیشه اول منوی 5 (BBR)** را اجرا کنید — تفاوت سرعت چشمگیر است.
2. برای فیلترینگ شدید: **FRP** (چون از داخل ایران به بیرون وصل می‌شود، نیازی به پورت باز روی ایران نیست).
3. برای مخفی‌سازی ترافیک: **Gost + WSS** (گزینه 7 منو) — ترافیک شبیه وبسایت معمولی دیده می‌شود.
4. برای چند سرور خارج: روی هر سرور خارج نصب کنید، سپس روی ایران چند بار نصب با IP های مختلف.
5. بعد از ریبوت سرور همه تانل‌ها خودکار بالا می‌آیند (systemd).

## 📁 مسیرهای مهم

| مسیر | توضیح |
|---|---|
| `/etc/myx/` | تنظیمات اصلی |
| `/etc/myx/tunnels/` | لیست تانل‌های نصب شده |
| `/etc/myx/frp/` | کانفیگ FRP (frps.toml / frpc.toml) |
| `/etc/myx/realm/` | کانفیگ Realm |
| `/usr/local/bin/myx` | دستور منو |
