# 🚀 MyX Tunnel v1.1.0

**تانل ریورس پرسرعت ایران ↔ خارج** — اسکریپت حرفه‌ای مدیریت تانل در سطح اسکریپت‌های معروف ایرانی، با منوی رنگی کامل و نصب تک‌دستوری.

---

## ⚡ نصب تک‌دستوری

اسکریپت را روی سرور (ایران یا خارج) آپلود کنید و بزنید:

```bash
bash myx-tunnel.sh
```

بعد از نصب اولین بار، دستور `myx` در هر جای سرور منوی مدیریت را باز می‌کند:

```bash
myx          # باز کردن منوی اصلی
myx menu     # باز کردن منو
myx version  # نمایش نسخه
```

برای انتشار عمومی (بعد از آپلود روی گیت‌هاب خودتان):

```bash
bash <(curl -Ls https://raw.githubusercontent.com/YOUR-USER/myx-tunnel/main/myx-tunnel.sh)
```

## 🔌 پروتکل‌های پشتیبانی شده

| پروتکل | نوع | بهترین کاربرد |
|---|---|---|
| **FRP** | ریورس واقعی (ایران به خارج وصل می‌شود) | فیلترینگ سنگین + IP ایران مسدود |
| **Realm** | فوروارد مستقیم TCP/UDP | سبک‌ترین و کم‌مصرف‌ترین |
| **Gost** | ریورس رمزنگاری‌شده (TLS / WS / WSS) | ضد DPI و دور زدن شناسایی ترافیک |
| **IPTables** | NAT سطح کرنل | کمترین تأخیر، حداکثر سرعت |
| **Socat** | فوروارد ساده TCP/UDP | تست سریع و راه‌اندازی آسان |

## 🛠 راه‌اندازی سریع (سناریوی استاندارد)

### مرحله ۱ — سرور خارج (Kharej)
```bash
bash myx-tunnel.sh
# 1) Install Tunnel (Wizard)
# 2) LISTENER side
# پروتکل را انتخاب کنید (مثلا FRP)
# پورت را وارد کنید
# ⚠️ توکن نمایش داده شده را کپی کنید!
```

### مرحله ۲ — سرور ایران (Iran)
```bash
bash myx-tunnel.sh
# 1) Install Tunnel (Wizard)
# 1) SERVICE / EXIT side
# همان پروتکل مرحله ۱
# IP سرور خارج + توکن + پورت سرویس لوکال (مثلا 443) + پورت روی خارج
```

✅ کاربران از پورت سرور خارج وصل می‌شوند و ترافیک از تانل به سرویس روی سرور ایران می‌رسد.

## 🔁 حالت برعکس (Reverse Mode) — IP ایران در کانفیگ، خروجی از خارج

اگر می‌خواهید کاربران به **IP سرور ایران** وصل شوند ولی خروجی اینترنتشان از **سرور خارج** باشد:

| سرور | انتخاب در Wizard | ورودی‌ها |
|---|---|---|
| **سرور ایران** | `2) LISTENER side` + IPTables / Realm / Socat | پورت لیستن روی ایران + **IP سرور خارج** به عنوان مقصد + پورت سرویس روی خارج |
| **سرور خارج** | (برای FRP برعکس) `1) SERVICE side` + FRP | IP سرور ایران + توکن + پورت سرویس روی خارج + پورت ریوت روی ایران |

⚠️ **شرط:** پورت لیستن روی سرور ایران باید برای کاربران ایرانی باز و قابل دسترسی باشد.

## 📋 امکانات منو

- **[1] Install Wizard** — نصب کامل با انتخاب نقش (ایران/خارج) و پروتکل
- **[2] Status** — وضعیت تمام تانل‌ها + پورت‌های فعال + BBR
- **[3] Remove** — حذف تک‌تک تانل‌ها
- **[4] Start/Stop/Restart** — کنترل همه سرویس‌ها
- **[5] Speed Optimization** — فعال‌سازی BBR + تنظیمات بافر شبکه (حداکثر سرعت)
- **[6] Speed Test** — تست سرعت سرور
- **[7] Anti-DPI Mode** — تبدیل Gost به WSS (استalth)، چرخش پورت، MSS Clamp
- **[8] Update** — بروزرسانی باینری‌ها
- **[9] Uninstall** — حذف کامل

## 🎯 نکات حرفه‌ای برای سرعت بالا

1. **همیشه اول منوی 5 (BBR)** را اجرا کنید — تفاوت سرعت چشمگیر است.
2. برای فیلترینگ شدید: **FRP** (چون از داخل ایران به بیرون وصل می‌شود، نیازی به پورت باز روی ایران نیست).
3. برای مخفی‌سازی ترافیک: **Gost + WSS** (گزینه 7 منو) — ترافیک شبیه وبسایت معمولی دیده می‌شود.
4. برای چند سرور خارج: روی هر سرور خارج نصب کنید، سپس روی ایران چند بار نصب با IP های مختلف.
5. بعد از ریبوت سرور همه تانل‌ها خودکار بالا می‌آیند (systemd).

## 📁 مسیرهای مهم

| مسیر | توضیح |
|---|---|
| `/etc/myx/` | تنظیمات اصلی |
| `/etc/myx/tunnels/` | لیست تانل‌های نصب شده |
| `/etc/myx/frp/` | کانفیگ FRP (frps.toml / frpc.toml) |
| `/etc/myx/realm/` | کانفیگ Realm |
| `/usr/local/bin/myx` | دستور منو |
